# LokiTunes Changelog

## v1.0.0 — Stable Candidate (Build 12)
- Android app version updated from 0.9.0 / build 11 to 1.0.0 / build 12.
- Updater now checks **installed and downloaded APK signing certificates match** before invoking the system package installer. Blocks a mismatched release early with an actionable explanation.
- Added pure JVM regression tests for signature guard.
- Added release checklist and end-to-end device QA instructions for first stable public release.
- No changes to playback, playlists, Favorites, lyrics or UI behavior.

## v0.9.0 — UI & Performance
- Short tab transitions; live mini-player progress; subtle Now Playing artwork transitions.
- Background song filtering, cached folder counts and retained song-list scroll position.

## v0.8.0 — Premium Audio
- Five-band equalizer, bass boost and sound presets with device-specific support.

## v0.7.0 — Smart Music Library
- Local playlists, advanced sorting and non-destructive potential duplicate detection.

## v0.6.0 — Smart Lyrics
- Local lyrics matching, opt-in LRCLIB search and local offline lyrics storage.

## v0.5.0 and earlier
- Lyrics, playback speed, device EQ shortcut, dynamic album colors, queue, sleep timer, Favorites backup, signed GitHub updater, core offline playback.
